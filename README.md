## 按使用场景选：多数人买 Single，两类人该往上走

只有一个成年人用 Mac 的家庭，Single 就够，买贵的部分是浪费。你自己两台机器，一台家里一台随身，也是 Single。

家里两三个人各有一台 Mac，才轮到 Family。判断方法很简单：这些电脑是不是不同的人在用。如果答案是否定的，Family 多出来的钱买的是“多用户”这个权利，你用不上。

## 常见问题

**Little Snitch 有免费版吗？**

没有长期免费版。官方提供演示模式，每次 3 小时、功能完整，用完可以无限次重开。这足够你判断要不要买，但不适合当日常使用方案。

**买了之后出第 7 版还要再付钱吗？**

现在不用。官网订购页写明当前授权同时适用于第 7 版和第 6 版。再往后的大版本，按官方一贯做法是老用户付费升级、给折扣价，目前公布的起点是 39 美元。

**一份 Single 能装几台 Mac？**

你自己名下的多台都可以装。不能的是多个人各自用自己的电脑共用一份。

**家里 3 台 Mac 该买 Family 吗？**

看是谁在用。如果是你一个人三台机器，Single 就覆盖了；如果是三个人各一台，才需要 Family。

**荔枝商店卖的授权能正常更新吗？**

更新走官方 App 内的更新通道，和你从哪里买无关。授权本身覆盖哪个大版本，以上面的版本政策为准。
